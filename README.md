# Островок радости Дизарди

Mobile-first, Russian-language static website for the children's entertainment center in Mineralnye Vody.

## Run locally

Open `index.html` directly or start a static server, for example:

```sh
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Test

Requires Node.js; run `npm test`.

## Business content

Prices, opening hours, phone number, address, venue floors, activity names and social links use details supplied for the business. Birthday cost and cafe menu are intentionally not listed. Current map artwork is illustrative rather than a geographic map. No venue photography was available; `ASSET_SOURCES.md` tracks this limitation.

## Publish

No Git repository or remote is configured. To publish through GitHub Pages, create or configure the authorized GitHub repository first, then enable Pages for its default branch.
